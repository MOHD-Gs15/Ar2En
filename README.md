# Ar2En — مترجم الشات من العربية إلى الإنجليزية 🎮

> الإصدار **1.1.0** — أضاف واجهة إعدادات GUI كاملة عبر ModMenu (بروفايلات، برومبت، موديل، مفتاح)

مود لماين كرافت **Java Edition إصدار 26.1.x** يحوّل رسائلك العربية إلى إنجليزية بأسلوب القازرز الحقيقي قبل إرسالها.

اكتب بالعربي في الشات → اضغط **Right Shift** → يستبدل المود النص في خانة الكتابة بترجمة إنجليزية طبيعية → راجعها واضغط **Enter** بنفسك.

```text
أنت تكتب:  والله إني متعب رح أغيب شوي، شو تسوي؟
تضغط:      Right Shift
تصبح:      im so tired rn, brb. wyd?
أنت تراجع ثم تضغط Enter — يصلها الجميع بالإنجليزية ✅
```

الذكاء الاصطناعي (عبر **Groq** المجاني) يفهم المشاعر والاختصارات والكتابة العفوية: `im, wyd, afk, u, rn, dang, gg` تبقى كما يكتبها اللاعبون الحقيقيون، لا ترجمة حرفية متكلفة.

## التثبيت

1. ثبّت **Fabric Loader** لأصدار 26.1.2 من: `https://fabricmc.net/use/installer`
2. حمّل **Fabric API** لإصدار 26.1 من Modrinth وضعها في مجلد `mods`
3. ضع ملف **`ar2en-1.1.0.jar`** (من صفحة Releases في هذا المستودع) في مجلد `mods` نفسه
4. (موصى به لكنه اختياري) حمّل **ModMenu** لإصدار 26.1 من Modrinth — ليعمل زر الإعدادات بالواجهة الرسومية
5. شغّل اللعبة واختر تثبيت Fabric

مجلد mods سريع الوصول: داخل اللعبة `Options → Resource Packs → Open Pack Folder` ثم ارجع مجلداً واحداً للخلف، أو ابحث عنه في `%appdata%\.minecraft\mods` (ويندوز).

> **ملاحظة**: المود يعمل بدون ModMenu كذلك — كل الإعدادات متاحة أيضاً عبر الأوامر، لكن الواجهة أسهل بكثير.

## واجهة الإعدادات الرسومية (ModMenu)

إن كنت مثبّتاً ModMenu: افتح قائمة المودات → اختر Ar2En → زر **الإعدادات**، وستجد:

| العنصر | ماذا يفعل |
|---|---|
| **الترجمة: مفعّل/معطّل** | تشغيل أو إيقاف المود كلياً بنقرة واحدة |
| **البروفايل ▼** | التبديل بين بطاقات الإعدادات المحفوظة (لكل بطاقة: موديل + مزودون + برومبت خاص بها) |
| **+ جديد** | إنشاء بروفايل جديد يلتقط إعداداتك الحالية باسم تختاره |
| **حذف** | حذف البروفايل المختار (لا يُحذف الأخير أبداً) |
| **الموديل ▼** | قائمة النماذج المعرّفة، اختر منها مباشرة |
| **جلب النماذج** | يستعلم Groq مباشرة عن النماذج المتاحة لمفتاحك ويحدّث القائمة فوراً |
| **المفتاح: Right Shift** | زر إعادة الربط: اضغطه ثم اضغط أي زر تريده ليصبح هو اختصار الترجمة (Esc للإلغاء) |
| **البرومبت: افتراضي/مخصص** | يفتح محرراً متعدد الأسطر للتعليمات المرسلة للذكاء الاصطناعي — عدّل أسلوب الترجمة كما تريد (رسمي، عامي، لهجة معينة...) وزر «افتراضي» يعيد سلانغ القازرز الأصلي |
| **خانة مفتاح Groq API** | الصق مفتاحك هنا مباشرة بدل أمر `/ar2en key` |
| **groq ✓ / libretranslate ✓ / google ✗** | تفعيل/تعطيل كل مزود في سلسلة الاحتياط بنقرة |

كل التغييرات تُحفظ فوراً في `config/ar2en.json`، و«تم — حفظ وإغلاق» يعيدك لقائمة المودات.

### البروفايلات — فكرة الاستخدام

أنشئ بروفايلات جاهزة وبدّل بينها حسب السياق، مثلاً:

- **القازرز** (الافتراضي): gpt-oss-120b + برومبت سلانغ القازرز
- **رسمي**: نفس الموديل لكن برومبت يفرض لغة مهذبة — للسيرفرات الجادة والمواظبات
- **سريع**: gpt-oss-20b للرد بأقل تأخير ممكن

التبديل بينها نقرة واحدة من قائمة البروفايل، وكل تعديل تفعله (موديل/برومبت/مزودون) يُحدّث البروفايل المختار تلقائياً فلا تفقد شيء.

## الحصول على مفتاح Groq مجاناً (دقيقة واحدة)

1. افتح `https://console.groq.com`
2. سجّل الدخول (يدعم التسجيل بحساب Google)
3. من القائمة الجانبية اختر **API Keys** ثم **Create API Key**
4. اكتب اسماً مثل `minecraft-ar2en` ثم انسخ المفتاح (يبدأ بـ `gsk_`)
5. داخل اللعبة اكتب:
   ```
   /ar2en key gsk_هنا_المفتاح_الخاص_بك
   ```
   أو الصقه في خانة المفتاح داخل واجهة الإعدادات، أو يدوياً في ملف `config/ar2en.json` داخل الحقل `groqApiKey`

> **الحدود المجانية**: حوالي 30 طلب/دقيقة و1000 طلب/يوم لنموذج gpt-oss-120b — أكثر من كافٍ لمحادثات اللعب اليومية، والمود يخزّن الرسائل المتكررة في الكاش فلا يستهلك طلبات إضافية.

> **لماذا Groq؟** لأنه الأسرع عالمياً (استجابة أقل من نصف ثانية بفضل معالجات LPU)، ومجاني، ونماذجه تُدرك النبرة العاطفية وسلانغ اللاعبين — بعكس المترجمات الحرفية التي تفسد اختصارات مثل `wyd` و`afk`.

## طريقة الاستخدام

1. اضغط **T** لفتح الشات واكتب رسالتك بالعربية
2. اضغط **Right Shift** (أو أي اختصار عيّنته)
3. ستظهر رسالة `⌛ جارٍ الترجمة...` فوق شريط الأدوات
4. خلال أقل من ثانية يُستبدل النص بالترجمة الإنجليزية داخل خانة الكتابة
5. راجعها، وعدّلها إن أردت، ثم اضغط **Enter** — لا يُرسل شيء بدون ضغطك Enter بنفسك

ملاحظات:
- إن غيّرت النص قبل اكتمال الترجمة فلن يكتب المود فوق كلماتك، بل يعرض الترجمة في الشات لتنسخها
- الرسائل التي تبدأ بـ `/` (أوامر) لا تُترجم أبداً
- إن لم يوجد نص عربي في الخانة فسيتجاهل الضغطة بهدوء
- إن أغلقت الشات قبل اكتمال الترجمة ستظهر لك النتيجة في الشات أيضاً

## الأوامر (تعمل داخل أي سيرفر — أوامر عميل محلية)

| الأمر | الوظيفة |
|---|---|
| `/ar2en` | عرض الحالة: مفعّل؟ المزودون، النموذج، هل المفتاح موجود |
| `/ar2en key <مفتاحك>` | حفظ مفتاح Groq في ملف الإعدادات (محلي على جهازك) |
| `/ar2en model quality` | التبديل للنموذج الأدق (gpt-oss-120b) — الأفضل لفهم المشاعر |
| `/ar2en model fast` | التبديل للنموذج الأسرع (gpt-oss-20b) |
| `/ar2en model <اسم_النموذج>` | استخدام أي نموذج من قائمة Groq بالاسم الكامل |
| `/ar2en models` | جلب قائمة النماذج المتاحة **لمفتاحك** مباشرة من Groq |
| `/ar2en provider <الاسم>` | تفعيل/تعطيل مزود: `groq` أو `libretranslate` أو `google` |
| `/ar2en toggle` | تشغيل/إيقاف المود كلياً |
| `/ar2en test <نص>` | تجربة الترجمة وعرض النتيجة في الشات دون تعديل خانة الكتابة |
| `/ar2en reload` | إعادة قراءة ملف الإعدادات بعد تعديله يدوياً |

## ملف الإعدادات `config/ar2en.json`

```json
{
  "enabled": true,
  "providers": ["groq", "libretranslate"],
  "groqApiKey": "",
  "groqModel": "openai/gpt-oss-120b",
  "groqModelQuality": "openai/gpt-oss-120b",
  "groqModelFast": "openai/gpt-oss-20b",
  "customPrompt": "",
  "profiles": [
    {
      "name": "القازرز",
      "model": "openai/gpt-oss-120b",
      "providers": ["groq", "libretranslate"],
      "prompt": ""
    }
  ],
  "activeProfile": 0,
  "knownModels": ["openai/gpt-oss-120b", "openai/gpt-oss-20b"],
  "hotkeyCode": 344,
  "libreUrl": "https://libretranslate.com/translate",
  "libreApiKey": "",
  "timeoutSeconds": 10,
  "cacheSize": 500
}
```

- **providers**: ترتيب المحاولة. يجرّب المود المزودين واحداً تلو الآخر حتى ينجح أحدهم
- **groqModel**: النموذج الحالي. أسماء النماذج لدى Groq تتغير مع الوقت — زر «جلب النماذج» في الواجهة (أو `/ar2en models`) يعرض المتاح فعلياً لمفتاحك
- **customPrompt**: برومبت مخصص يُرسل بدل الافتراضي — فارغ = سلانغ القازرز الأصلي
- **profiles / activeProfile**: البطاقات المحفوظة وترتيبها — من إعدادات الواجهة أو يدوياً
- **hotkeyCode**: رمز GLFW لاختصار الترجمة (344 = Right Shift) — يتغير تلقائياً عند إعادة الربط من الواجهة
- **libreUrl / libreApiKey**: نقطة نهاية LibreTranslate (انظر الأسفل)

### جعل النظام مجانياً 100% بدون أي مفتاح (اختياري)

شغّل خادم LibreTranslate على جهازك أو على سيرفر تملكه:

```bash
docker run -ti --rm -p 5000:5000 libretranslate/libretranslate
```

ثم عدّل في `config/ar2en.json`:

```json
"libreUrl": "http://localhost:5000/translate"
```

وبإمكانك تعطيل groq نهائياً (`/ar2en provider groq` أو حذفه من providers) — ستعمل الترجمة بعدئذٍ بلا أي مفتاح أو حساب. الدقة أقل من الذكاء الاصطناعي في فهم المشاعر، لكنها مجانية وغير محدودة.

كذلك يوجد مزود ثالث جاهز بالكود لكنه معطّل افتراضياً: `google` (نقطة الترجمة المجانية بدون مفتاح). فعّله بـ `/ar2en provider google`.

## تغيير الاختصار

من الواجهة (ModMenu → Ar2En → الإعدادات): اضغط زر **المفتاح** ثم اضغط الزر الذي تريده.

أو بالطريقة القديمة: `Options → Controls → Key Binds → Miscellaneous → Translate my chat (Arabic → English)`

الافتراضي **Right Shift**. اختر زراً لا تستخدمه للكتابة في الشات (الضغط عليه أثناء فتح الشات يُستهلك للمود ولا يُكتب حرفياً).

## البناء من المصدر

```bash
# يتطلب JDK 25 فقط — كل شيء آخر يُنزّل تلقائياً
./gradlew build          # على ويندوز: gradlew.bat build
```

النتيجة في `build/libs/ar2en-1.1.0.jar` (تجاهل ملف `-sources`).

هيكل المشروع يتبع قالب Fabric الرسمي الحديث: الكود كله داخل `src/client/java` (مود عميل خالص)، والإعدادات والموارد داخل `src/client/resources`.

## بنية الكود

| الملف | الدور |
|---|---|
| `Ar2EnClient.java` | نقطة الدخول: تسجيل الاختصار، ربط أحداث لوحة المفاتيح داخل شاشة الشات، الأوامر |
| `ChatTranslator.java` | منطق الضغطة: قراءة نص الخانة، فحص العربية، الترجمة، الاستبدال الآمن |
| `TranslationService.java` | سلسلة المزودين بالترتيب + كاش LRU للرسائل المتكررة |
| `providers/GroqProvider.java` | استدعاء Groq (متوافق OpenAI) مع التعليمات التي تفرض أسلوب سلانغ القازرز |
| `providers/LibreTranslateProvider.java` | الاحتياطي مفتوح المصدر |
| `providers/GoogleProvider.java` | خيار مجاني بلا مفتاح (معطّل افتراضياً) |
| `mixin/ChatScreenAccessor.java` | فتح الوصول لحقل نص الشات `input` |
| `gui/Ar2EnModMenu.java` | ربط ModMenu: زر الإعدادات في قائمة المودات |
| `gui/Ar2EnConfigScreen.java` | شاشة الإعدادات الرئيسية (بروفايلات، موديل، مفتاح، مزودون...) |
| `gui/PromptEditScreen.java` | محرر البرومبت متعدد الأسطر |
| `gui/ProfileNameScreen.java` | نافذة تسمية البروفايل الجديد |

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| `Groq: مفتاح API غير صالح (401)` | تأكد من نسخ المفتاح كاملاً بدءاً بـ `gsk_` — أعد ضبطه بـ `/ar2en key` |
| `Groq: تجاوزت الحد (429)` | انتظر دقيقة أو بدّل مؤقتاً لنموذج أسرع؛ الكاش يقلل الاستهلاك تلقائياً |
| `النموذج غير متوفر` | أسماء النماذج تتغير — نفّذ `/ar2en models` واختر اسم موجود |
| المود لا يترجم إطلاقاً | `/ar2en` للفحص: هل مفعّل؟ هل المفتاح موجود؟ وتأكد أن الاختصار مضبوط من Controls |
| خطأ mixin عند الإقلاع على إصدار غير 26.1.x | هذا المود مبني لسلسلة 26.1 فقط؛ عدّل `minecraft_version` في `gradle.properties` وأعد البناء للإصدارات الأحدث |
| اتصال LibreTranslate يفشل | الموقع العام يحتاج مفتاحاً أحياناً — استخدم استضافة ذاتية بالأمر أعلاه |

## الخصوصية

رسائلك التي تختار ترجمتها تُرسل إلى مزود الترجمة المفعّل (Groq أو غيره) لمعالجتها. المود لا يرسل شيئاً إلا عند ضغطك الاختصار، ولا يتصل بأي خادم آخر، والمفتاح يبقى في ملف إعدادات على جهازك.
